# CAT_Test01_Adaptive_EchoAdapt

This content package contains 1 test with 1 test part with 3 sections:
- section 1 contains one informational item (CAT00) with no interaction
- section 2 contains 9 scorable items (CAT01-09), across 3 difficulties (easy, medium, hard) and 3 topics (A, B, C); the item are all identical and present 2 options (correct, incorrect)
- section 3 contains one informational item (CAT99) with no interaction

The test is configured to use the ACT EchoAdapt Service.
